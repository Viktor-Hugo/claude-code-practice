# PRD: TodoList 웹앱

## 배경 및 목적
할 일을 적고, 완료 여부를 표시하고, 지울 수 있는 간단한 웹앱입니다. 빌드 도구나 서버 없이 `index.html` 하나만 브라우저로 열면 바로 실행됩니다. 브라우저 새로고침이나 재실행 후에도 목록이 그대로 남아 있어야 합니다.

## 대상 사용자
자기 할 일을 관리하는 개인 사용자 1명입니다. 한 브라우저에서만 쓰며, 계정 구분은 없습니다.

## 요구사항
1. **할 일 추가**: 입력창에 내용을 쓰고 "추가" 버튼을 누르거나 Enter를 치면 목록에 추가됩니다. 추가한 뒤 입력창은 비워집니다.
2. **빈 입력 방지**: 빈 문자열이나 공백만 있는 입력은 추가되지 않습니다. 앞뒤 공백은 잘라내고 저장합니다.
3. **목록 표시**: 저장된 할 일을 모두 추가한 순서대로 보여줍니다. 새 항목은 맨 아래에 붙습니다.
4. **완료 체크/해제**: 각 항목의 체크박스로 완료 상태를 켜고 끌 수 있습니다. 완료된 항목은 취소선으로 구분합니다.
5. **삭제**: 각 항목의 "삭제" 버튼을 누르면 확인 창 없이 바로 지워집니다.
6. **유지**: 추가·체크·삭제가 일어날 때마다 localStorage에 저장하고, 페이지를 열면 저장된 목록을 다시 불러옵니다.

## 범위
### 포함 (In Scope)
- 할 일 추가, 목록 표시, 완료 체크/해제, 삭제
- localStorage로 목록 유지
- 순수 HTML/CSS/JavaScript 사용, `index.html` 실행

### 제외 (Out of Scope)
- 로그인 및 사용자 계정
- 서버, DB, 외부 API
- 마감일, 카테고리
- 디자인 프레임워크(Bootstrap, Tailwind 등)와 빌드 도구(npm, 번들러)
- 할 일 내용 수정, 정렬 변경, 필터링

## 성공 지표: 완료 조건 (입력 → 기대 결과)
| # | 입력 | 기대 결과 |
|---|------|-----------|
| 1 | `index.html`을 브라우저로 직접 열기 | 콘솔 에러 없이 입력창, 추가 버튼, 빈 목록이 보임 |
| 2 | "우유 사기" 입력 후 "추가" 클릭 | 목록에 "우유 사기"가 추가되고 입력창이 비워짐 |
| 3 | "책 읽기" 입력 후 Enter | 목록 맨 아래에 "책 읽기"가 추가됨 |
| 4 | 아무것도 입력하지 않고 "추가" 클릭 | 목록에 변화 없음 |
| 5 | 공백만 입력(`"   "`)하고 "추가" 클릭 | 목록에 변화 없음 |
| 6 | `"  운동  "` 입력 후 추가 | 앞뒤 공백이 잘린 "운동"으로 추가됨 |
| 7 | "우유 사기"의 체크박스 클릭 | 체크 표시와 함께 취소선이 생김 |
| 8 | 체크된 "우유 사기"의 체크박스 다시 클릭 | 체크와 취소선이 해제됨 |
| 9 | "책 읽기"의 "삭제" 클릭 | "책 읽기"만 목록에서 사라짐 |
| 10 | 항목 몇 개를 추가하고 하나를 체크한 뒤 새로고침(F5) | 항목, 순서, 체크 상태가 새로고침 전과 똑같음 |
| 11 | 브라우저 탭을 닫았다가 `index.html`을 다시 열기 | 직전 목록과 체크 상태가 그대로 보임 |
| 12 | 모든 항목 삭제 후 새로고침 | 빈 목록이 표시됨(삭제한 항목이 다시 나타나지 않음) |

## 확정된 결정 사항
초안에서 가정했던 내용으로, 사용자 승인(2026-10-02)으로 확정했습니다.
1. **정렬**: 새 항목은 목록 맨 아래에 추가하고, 완료된 항목도 자리를 옮기지 않습니다.
2. **삭제 확인**: 삭제할 때 확인 창(confirm)을 띄우지 않습니다.
3. **빈 입력 피드백**: 빈 입력은 경고 문구나 alert 없이 그냥 무시합니다.
4. **수정 기능**: 이미 추가한 할 일의 내용을 고치는 기능은 이번 범위에서 뺍니다.
5. **완료 표시 방식**: 완료된 항목은 체크박스와 취소선으로 구분합니다.
